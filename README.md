# Dynamic Reporting & Data Visualization Using SQL (Virtual Retail Environment)

## 📌 Project Overview
This repository contains the SQL analytical queries, mock reporting data, visual chart blueprints, and technical documentation for **Week 4: Dynamic Reporting and Data Visualization Using SQL**. 

The project focuses on transforming raw relational retail data into dynamic business intelligence insights across four critical domains: Product Sales Rankings, Inventory Turnover, Seasonal Sales Trends, and Customer RFM Segmentation.

---

## 💡 Core Analytical Scenarios & SQL Concepts

### 1. Best-Selling Products & Category Revenue Share
- **SQL Concepts:** `SUM() OVER(PARTITION BY...)`, `DENSE_RANK()`, CTEs, Multi-table JOINs.
- **Visualization:** Pareto Chart (Dual-Axis Bar & Cumulative Percentage Line).

### 2. Inventory Turnover Rate & Stock-Out Risk Profiling
- **SQL Concepts:** COGS Calculation, Average Inventory Aggregation, Conditional Case Statements (`CASE WHEN`).
- **Visualization:** Dual-Axis Column Chart & KPI Gauge Metrics.

### 3. Seasonal Sales Trends & Month-over-Month (MoM) Growth
- **SQL Concepts:** Time-series analytical window functions (`LAG() OVER(...)`), Date Truncation (`DATE_TRUNC`), Variance Calculations.
- **Visualization:** Multi-Series Line Chart with Trendlines & MoM Growth Bars.

### 4. Customer RFM Segmentation & Lifetime Spend
- **SQL Concepts:** `DATEDIFF`, `NTILE(4)`, CTE Aggregations, Behavioral Rule Engine Scoring.
- **Visualization:** 4-Quadrant Bubble Matrix & Customer Segment Treemap.

## 📊 Summary of Visualization Blueprints

| Scenario | Analytical Focus | Key Metrics | Primary Recommended Visual |
| :--- | :--- | :--- | :--- |
| **Scenario 1** | Product & Category Performance | Revenue, Category Share %, Volume | Pareto Combination Chart |
| **Scenario 2** | Supply Chain & Stock Health | Turnover Ratio, Days on Hand, COGS | Dual-Axis Column + Gauge |
| **Scenario 3** | Temporal Revenue & Seasonality | Total Sales, MoM Growth %, Prior Sales | Multi-Line Chart + Bar Variance |
| **Scenario 4** | Customer RFM Behavior | Recency, Frequency, Monetary Value | 4-Quadrant Scatter / Treemap |
